# daily-lab 🧪

An **autonomous daily generative-art lab**. Every day, a scheduled script on my machine produces a handful of brand-new, procedurally-generated SVG artworks — cellular automata, mazes, flow fields, circle packings, Truchet tilings, chaos-game fractals — and commits each one here.

This repo is automation — disclosed and on purpose. It is **deterministic and runs with zero AI cost**: each piece is generated by a small stdlib Python program ([`bin/generate.py`](../github_activity/bin/generate.py) on my machine), seeded by the date so every artwork is reproducible yet unique. A varying number of pieces is produced each day, so the history looks bursty and human rather than flat.

## How it works

1. A `launchd` agent fires at login and hourly; the first run each day does the work, then marks the day done.
2. It picks a random daily count (1–25) and runs the generator, which writes each artwork into `pieces/YYYY-MM-DD/` and commits it individually.
3. The runner pushes the day's commits.

Everything is pure `python3` stdlib — no dependencies, no network, no API calls.
